Open Graph and Twitter Card meta tags for posts, pages and the home
page, so shared links show a proper title, description and image.

== Description ==

Adds Open Graph and Twitter Card meta tags to the head of every
public page. Titles come from the post title (or site name and
tagline on the home page), descriptions from the excerpt, and images
from the featured image — falling back to the first image in the
content, a default image from Settings > Open Graph, and finally the
site icon.

== Installation ==

1. In WordPress admin, go to Plugins > Add New > Upload Plugin and
   choose the release zip.
2. Activate WP Open Graph.
3. Optional: open Settings > Open Graph and set a default image.
